
## 1. Python 기초

### 변수(Variable)
변수는 데이터를 담는 데이터 상자라고 생각하면 쉽습니다. 컴퓨터 메모리 어딘가에 값을 저장하고, 이름을 붙여서 나중에 다시 꺼내 쓰기 위해 사용합니다.

### 데이터 타입(Data Types)
int (Integer): 정수 (예: 10, -5)

str (String): 문자열 (예: "Hello")

bool (Boolean): 참/거짓 (예: True, False)

list: 순서가 있는 값들의 모임 (예: [1, 2, 3])

dict (Dictionary): 키(Key)와 값(Value)의 쌍 (예: {"name": "Alice"})

### 조건문과 반복문
if / elif / else: 특정 조건이 참일 때만 코드를 실행합니다.

for vs while:

for: 리스트나 범위처럼 정해진 횟수만큼 반복할 때 유리합니다.

while: 조건이 참인 동안 무한히 반복해야 할 때(횟수가 불확실할 때) 사용합니다.

### 함수(Function)
반복되는 코드를 묶어둔 기능 단위입니다.

매개변수(Parameter): 함수에 전달하는 입력값.

반환값(Return): 함수가 일을 끝내고 돌려주는 결과값.

## 2. 클래스와 객체
클래스(Class)란?
클래스는 객체를 만들기 위한 **설계도(붕어빵 틀)**입니다. 비슷한 특징을 가진 객체들을 효율적으로 생성하기 위해 사용합니다.

### 핵심 개념
self: '나 자신'을 가리킵니다. 클래스 내부에서 자기 자신의 속성에 접근할 때 사용합니다.

__init__: 객체가 생성될 때 자동으로 호출되는 초기화 메서드입니다.

속성(Attribute): 객체가 가진 상태(변수).

메서드(Method): 객체가 할 수 있는 행동(함수).

## 3. 파일 입출력 및 예외 처리
### 파일 처리 프로세스
Open: 파일을 엽니다. ('r' 읽기, 'w' 쓰기)

Read/Write: 내용을 읽거나 씁니다.

Close: 파일을 닫아 메모리를 해제합니다. (파이썬의 with 구문을 쓰면 자동으로 닫힙니다.)

### JSON 형식
데이터를 저장하거나 주고받을 때 사용하는 표준 형식입니다. 파이썬의 dict와 매우 비슷하게 생겨서 가독성이 좋고 가볍습니다.

### 오류 처리 (try/except)
프로그램이 에러 때문에 갑자기 멈추는 것을 방지합니다. 에러가 날 것 같은 코드를 try에 넣고, 에러 발생 시 대처법을 except에 작성합니다.

## 4. Git 기초
### Git이란?
코드의 **변경 이력을 관리하는 시스템(버전 관리)**입니다. 실수를 되돌리거나 여러 명이 협업할 때 필수적입니다.

### 주요 명령어
init: 현재 폴더를 Git 저장소로 만듭니다.

add: 변경 사항을 저장할 준비를 합니다 (장바구니에 담기).

commit: 현재 상태를 영구적으로 기록합니다 (결제 완료).

push: 내 컴퓨터의 기록을 서버(GitHub 등)에 올립니다.

pull: 서버의 최신 내용을 내 컴퓨터로 가져옵니다.

clone: 원격 저장소를 통째로 내 컴퓨터로 복사해옵니다.

checkout: 다른 브랜치로 이동합니다.

### 브랜치(Branch)와 병합(Merge)
브랜치: 원본 코드를 건드리지 않고 새로운 기능을 개발하기 위해 만든 '가지'입니다.

병합: 개발이 끝난 가지를 다시 메인 코드에 합치는 과정입니다.
