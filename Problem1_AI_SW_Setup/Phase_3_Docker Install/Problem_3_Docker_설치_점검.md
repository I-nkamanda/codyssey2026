## Docker 설치 여부 확인

Docker 및 다른 많은 프로그램의 설치 여부를 확인하려고 하면 version 확인만한 게 잘 없다.

왜냐하면, 설치되지 않은 program의 --version을 찾아본다면 반드시 에러 메시지가 뜨기 때문이다.

```bash

ersatzvitamin9579@c4r3s1 codyssey2026 % docker --version
Docker version 28.5.2, build ecc6942 #다음과 같이 버전 및 빌드 정보가 같이 나옴을 알 수 잇다.
ersatzvitamin9579@c4r3s1 codyssey2026 % 


```
