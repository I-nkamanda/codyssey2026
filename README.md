## **프로젝트 개요**
본 미션의 목표는 어디에서든 같은 환경으로 작업할 수 있는 AI / SW 작업 환경을 구축하는 것이다.
이를 통해 교육생은 앞으로도 Mac/Linux/Windows 등 다양한 환경에 처했더라도 개발 및 AI 작업을 일관적으로 수행할 수 있게 될 것이다.
